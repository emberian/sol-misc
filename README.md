# sol-misc

Small Solana things from the dregg workshop, each in its own directory. Pages for the ones
with a page live under `docs/` (GitHub Pages: https://emberian.github.io/sol-misc/).

- [`otc/`](otc/) — dregg-otc, a passphrase-claimable token escrow: a Verus-verified pure core (no allocator),
  a thin pinocchio adapter, [PROPERTIES.md](otc/PROPERTIES.md), a claim/make page at
  [`/sol-misc/otc/`](https://emberian.github.io/sol-misc/otc/) and a deploy/upgrade/close page at
  [`/sol-misc/otc/deploy.html`](https://emberian.github.io/sol-misc/otc/deploy.html).
