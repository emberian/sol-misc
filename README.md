# sol-misc

Small Solana things from the dregg workshop, each in its own directory. Pages for the ones
with a page live under `docs/` (GitHub Pages: https://emberian.github.io/sol-misc/).

- [`passwap/`](passwap/) — passwap, a passphrase-claimable token escrow: a Verus-verified pure core (no allocator),
  a thin pinocchio adapter, 2-of-3 multisig custody so nothing depends on the program, [PROPERTIES.md](passwap/PROPERTIES.md),
  a claim/make page at [`/sol-misc/passwap/`](https://emberian.github.io/sol-misc/passwap/), user docs at
  [`protocol.html`](https://emberian.github.io/sol-misc/passwap/protocol.html) and a deploy page at
  [`deploy.html`](https://emberian.github.io/sol-misc/passwap/deploy.html).
