# sol-misc

Small Solana things from the dregg workshop, each in its own directory. Pages for the ones
with a page live under `docs/` (GitHub Pages: https://emberian.github.io/sol-misc/).

- [`otc/`](otc/) — dregg-otc, a passphrase-claimable token escrow: a verified pure core, a thin SBF
  adapter, and a static claim/make page at [`/sol-misc/otc/`](https://emberian.github.io/sol-misc/otc/).
